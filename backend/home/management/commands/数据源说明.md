# 中文圣训集数据源说明

## 当前可用的中文圣训集数据源

由于中文圣训集资源相对有限，以下是获取数据的几种方式：

### 方式一：从本地文件导入（最推荐）

如果你已经有中文圣训集的文本或PDF文件：

1. **准备数据文件**：
   - 将圣训集内容整理成TXT或JSON格式
   - 确保使用UTF-8编码
   - 参考 `example_hadith_data.json` 的格式

2. **导入数据**：
   ```bash
   cd backend
   python manage.py crawl_hadith --source local_file --file path/to/your/data.json --collection "布哈里圣训集"
   ```

### 方式二：从网站爬取

#### 可能的中文圣训集网站：

1. **伊斯兰之家 (islamhouse.com)**
   - 网址：https://islamhouse.com/zh/books/
   - 提供部分中文伊斯兰书籍
   - 需要找到具体的圣训集页面URL

2. **中穆网**
   - 可能有部分圣训内容
   - 需要检查网站结构

3. **各地方伊斯兰协会网站**
   - 可能提供本地化的圣训内容

**使用方法**：
```bash
python manage.py crawl_hadith --source islamhouse --url "具体页面URL" --collection "布哈里圣训集"
```

### 方式三：手动整理

如果找不到现成的数据源：

1. **从PDF提取**：
   - 打开圣训集PDF文件
   - 复制文本内容
   - 整理成标准格式（参考示例文件）

2. **从书籍录入**：
   - 手动输入或使用OCR
   - 整理成JSON或TXT格式
   - 导入数据库

## 数据格式要求

### JSON格式（推荐）：
```json
{
  "collection": "布哈里圣训集",
  "chapters": [
    {
      "title": "第一章：信仰的开始",
      "content": "章节内容..."
    }
  ]
}
```

### TXT格式：
```
第一章：信仰的开始
这是第一章的内容...

第二章：清洁
这是第二章的内容...
```
