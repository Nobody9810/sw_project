# 从伊斯兰之家网站爬取中文圣训集 - 使用说明

## 快速开始

### 1. 安装依赖

```bash
cd backend
pip install beautifulsoup4 lxml
```

### 2. 查找目标页面URL

访问伊斯兰之家网站：https://islamhouse.com/zh/books/

搜索或浏览找到你想要爬取的中文圣训集页面，复制页面URL。

### 3. 执行爬取命令

```bash
python manage.py crawl_hadith --source islamhouse --url "页面URL" --collection "布哈里圣训集"
```

**示例**：
```bash
python manage.py crawl_hadith --source islamhouse --url "https://islamhouse.com/zh/books/123456" --collection "布哈里圣训集"
```

## 命令参数说明

### 必需参数
- `--source islamhouse`: 指定数据源为伊斯兰之家网站

### 可选参数
- `--url`: 目标页面URL（必需，如果未提供会提示）
- `--collection`: 圣训集名称，默认"布哈里圣训集"
- `--delay`: 请求间隔（秒），默认2秒，避免对服务器造成压力
- `--dry-run`: 试运行模式，不实际保存数据，用于测试

## 使用示例

### 1. 试运行（推荐先执行）
```bash
python manage.py crawl_hadith --source islamhouse --url "https://islamhouse.com/zh/books/xxx" --collection "布哈里圣训集" --dry-run
```

这会显示将要爬取的内容，但不会保存到数据库。

### 2. 正式爬取
```bash
python manage.py crawl_hadith --source islamhouse --url "https://islamhouse.com/zh/books/xxx" --collection "布哈里圣训集"
```

### 3. 自定义请求间隔
如果网站响应较慢，可以增加延迟：
```bash
python manage.py crawl_hadith --source islamhouse --url "https://islamhouse.com/zh/books/xxx" --collection "布哈里圣训集" --delay 3
```

## 爬虫功能说明

### 支持的页面类型

1. **章节列表页**：如果页面包含目录链接，爬虫会自动爬取每个章节的详细内容
2. **单页内容**：如果所有内容在一个页面，爬虫会解析章节结构
3. **PDF链接检测**：如果检测到PDF链接，会提示你下载PDF后手动提取

### 解析策略

爬虫使用多种策略解析页面内容：

1. **目录解析**：查找页面中的目录（TOC），自动爬取每个章节
2. **标题解析**：查找包含"第X章"的标题，提取章节内容
3. **段落解析**：如果没有明确的章节结构，按段落分组
4. **内容区域解析**：查找主要内容区域（article、main等标签）

### 数据保存

- 数据保存到 `经训` 和 `章节_经训` 表
- 如果章节已存在，会跳过（不会重复创建）
- 所有章节默认设置为已发布状态

## 常见问题

### Q1: 提示"未找到章节数据"
**可能原因**：
- 页面结构不同，需要调整解析逻辑
- 内容在PDF文件中
- 需要登录才能访问

**解决方法**：
1. 检查页面是否可以直接访问
2. 如果内容在PDF中，下载PDF后使用PDF提取工具
3. 使用 `--dry-run` 查看调试信息
4. 查看生成的 `islamhouse_debug.html` 文件分析页面结构

### Q2: 爬取速度很慢
**原因**：为了避免对服务器造成压力，默认设置了2秒延迟

**解决方法**：
- 如果确定可以加快速度，可以减少 `--delay` 参数
- 但建议保持至少1秒的延迟，遵守网站使用规范

### Q3: 某些章节内容为空
**可能原因**：
- 章节链接无效
- 章节页面需要特殊权限
- 网络请求失败

**解决方法**：
- 检查章节URL是否可访问
- 查看错误信息
- 手动访问章节页面确认

### Q4: 如何爬取多个圣训集？
**方法**：
分别执行爬取命令，使用不同的 `--collection` 参数：

```bash
python manage.py crawl_hadith --source islamhouse --url "URL1" --collection "布哈里圣训集"
python manage.py crawl_hadith --source islamhouse --url "URL2" --collection "穆斯林圣训集"
```

## 注意事项

1. **遵守网站使用规范**：
   - 不要过于频繁地请求
   - 遵守网站的robots.txt
   - 尊重网站的服务条款

2. **数据准确性**：
   - 爬取后请检查数据完整性
   - 某些特殊格式可能需要手动调整

3. **版权问题**：
   - 确保你有权使用这些数据
   - 遵守相关版权规定

4. **网络问题**：
   - 如果网络不稳定，可能需要多次尝试
   - 可以分段爬取，使用不同的URL
