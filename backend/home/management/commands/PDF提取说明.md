# PDF文本提取说明

## 功能概述

爬虫现在支持从PDF文件提取中文圣训集数据。支持两种方式：
1. **本地PDF文件**：从本地文件系统读取PDF
2. **PDF URL**：从网络下载PDF后提取

## 准确性说明

### PDF类型和准确性

#### 1. 文本型PDF（可选中文本）✅ **准确率：95-99%**

**特点**：
- PDF中的文字是真正的文本，可以选中复制
- 通常由Word、LaTeX等文档软件生成
- 文本提取准确率很高

**准确性**：
- ✅ 文本内容：几乎100%准确
- ✅ 章节结构：取决于PDF格式，通常能正确识别
- ⚠️ 格式：可能丢失部分格式（如粗体、斜体）
- ⚠️ 表格：可能需要手动调整

**适用场景**：
- 现代出版的电子版圣训集
- 从Word转换的PDF
- 结构清晰的PDF文档

#### 2. 扫描型PDF（图片）❌ **需要OCR，准确率：70-90%**

**特点**：
- PDF中只有图片，没有文本
- 通常是扫描纸质书籍生成
- 需要OCR（光学字符识别）才能提取文本

**准确性**：
- ⚠️ 文本内容：取决于OCR质量，通常70-90%
- ⚠️ 章节结构：可能识别不准确
- ❌ 格式：基本丢失
- ❌ 特殊字符：可能识别错误

**解决方法**：
- 使用专业的OCR工具（如ABBYY FineReader、Tesseract）
- 手动校对重要内容
- 考虑使用其他数据源

**不适用场景**：
- 当前脚本不支持OCR
- 需要先使用OCR工具转换为文本型PDF

#### 3. 加密/受保护PDF ⚠️ **需要密码**

**特点**：
- PDF设置了密码保护
- 需要密码才能打开

**解决方法**：
- 提供PDF密码（如果脚本支持）
- 或先解密PDF再提取

## 使用方法

### 1. 安装依赖

**推荐使用 pdfplumber**（对中文支持更好）：
```bash
pip install pdfplumber
```

**或者使用 PyPDF2**：
```bash
pip install PyPDF2
```

### 2. 从本地PDF提取

```bash
python manage.py crawl_hadith --source pdf --file path/to/hadith.pdf --collection "布哈里圣训集"
```

**示例**：
```bash
python manage.py crawl_hadith --source pdf --file ~/Downloads/bukhari.pdf --collection "布哈里圣训集"
```

### 3. 从PDF URL提取

```bash
python manage.py crawl_hadith --source pdf --url "https://example.com/hadith.pdf" --collection "布哈里圣训集"
```

**示例**：
```bash
python manage.py crawl_hadith --source pdf --url "https://islamhouse.com/files/books/hadith.pdf" --collection "布哈里圣训集"
```

### 4. 试运行（推荐先测试）

```bash
python manage.py crawl_hadith --source pdf --file path/to/hadith.pdf --collection "布哈里圣训集" --dry-run
```

## 提取过程

### 步骤1：文本提取
- 逐页提取PDF中的文本
- 显示处理进度

### 步骤2：文本清理
- 移除多余的空白
- 清理页眉页脚
- 移除页码

### 步骤3：章节解析
- 自动识别章节标题（如"第一章"、"Chapter 1"等）
- 将文本分割为章节
- 如果没有明确的章节结构，按段落分组

### 步骤4：数据保存
- 保存到数据库
- 显示保存的章节数量

## 准确性影响因素

### ✅ 提高准确性的因素

1. **PDF质量好**
   - 文本型PDF（非扫描）
   - 结构清晰
   - 章节标题格式统一

2. **格式规范**
   - 章节标题明显（如"第一章"）
   - 段落分隔清晰
   - 没有复杂的表格或图片

3. **中文支持**
   - PDF使用标准中文字体
   - 编码正确（UTF-8）

### ⚠️ 降低准确性的因素

1. **PDF格式复杂**
   - 复杂的表格
   - 多栏布局
   - 图片中的文字

2. **结构不清晰**
   - 没有明确的章节标题
   - 段落分隔不明显
   - 格式混乱

3. **扫描版PDF**
   - 需要OCR
   - 当前脚本不支持

## 常见问题

### Q1: 提取的文本有乱码？

**可能原因**：
- PDF使用了特殊字体或编码
- 中文字体嵌入问题

**解决方法**：
1. 尝试使用不同的PDF库（pdfplumber vs PyPDF2）
2. 检查PDF是否可以在其他软件中正常打开
3. 考虑手动复制文本

### Q2: 章节识别不准确？

**可能原因**：
- PDF中章节标题格式不统一
- 没有明确的章节标记

**解决方法**：
1. 使用 `--dry-run` 查看提取结果
2. 手动调整章节结构
3. 从提取的文本手动整理成JSON格式，然后使用 `--source local_file` 导入

### Q3: 提取速度很慢？

**可能原因**：
- PDF文件很大
- 页面很多

**解决方法**：
- 这是正常的，大文件需要时间处理
- 脚本会显示进度

### Q4: 某些页面提取失败？

**可能原因**：
- 页面是图片（扫描版）
- 页面格式特殊
- PDF损坏

**解决方法**：
1. 检查PDF是否可以在其他软件中正常打开
2. 如果是扫描版，需要先OCR
3. 尝试使用其他PDF工具提取

### Q5: 如何提高准确性？

**建议**：
1. **预处理PDF**：
   - 确保PDF是文本型（非扫描）
   - 统一章节标题格式
   - 清理不必要的页眉页脚

2. **后处理数据**：
   - 提取后检查数据
   - 手动调整章节结构
   - 校对重要内容

3. **使用合适的工具**：
   - 推荐使用 `pdfplumber`（对中文支持更好）
   - 复杂PDF可以尝试多个工具

## 与网站爬取的对比

| 特性 | PDF提取 | 网站爬取 |
|------|---------|----------|
| **准确性** | 95-99%（文本型PDF） | 取决于网站结构 |
